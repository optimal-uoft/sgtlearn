## Suspicions

### sgtlearn-export-py--draw-internal-panel-categorical

Logical mistakes:
- Each bin's background band is drawn with a height equal to that bin's normalised count. The band is supposed to show which partition a bin routes to, whatever the data says, so it should fill the full height of the panel. The fallback value of 1.0 for the height points the same way. As written, the band is redundant with the bar drawn on top of it. Worse, bins with no samples get no colour at all, and when X_rows is None or empty every band is zero-height, so the panel shows no partition colouring.
- Bins are counted from bin_to_partition, but tick labels come from the category-label list. If that list is shorter than the number of bins, there are fewer labels than ticks and some bins go unlabelled. Current matplotlib raises an error when the label count does not match the tick count.

Robustness omissions:
- The bin index returned for a sample's active one-hot column is used without a range check. A category that is unknown or missing, or that maps outside the known bins, can raise IndexError, or silently add to the wrong bin through negative indexing.
- Partition indices are used to index the palette without checking they are within its length.
- The node must contain "n_samples" when a label is requested, or a KeyError is raised. It is never checked.
- The smaller font size (fontsize - 2) can be zero or negative when fontsize is very small. Also, bool counts as an int in the type check.
- An inset axes is created and returned even when the node has no bins. This is acceptable, but it should be documented.
