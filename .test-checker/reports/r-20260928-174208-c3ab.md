### sgtlearn-base-py--warn-if-mae-cd-disabled

Logical mistakes: The opt-in environment variable check is inconsistent about case. The criterion is normalized (whitespace stripped, lowercased) before comparison, but SGTLEARN_MAE_CD is compared exactly against a fixed set. "1", "true", "TRUE" and "yes" count as enabled, while "True", "YES", "Yes" or " true " do not. Accepting both "true" and "TRUE" shows the check is meant to be case-insensitive. The criterion itself is handled safely: non-string or None values are converted to text and never match. Nothing else is missing. The function should never raise.
