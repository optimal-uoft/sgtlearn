## Suspicions

### sgtlearn-multioutput-py--squeeze-outputs

Logical mistakes: none found on the happy path. When n_outputs == 1 and the input is a column vector of shape (n_samples, 1) or already 1-D (n_samples,), the result is the expected 1-D vector of length n_samples, in row order. When n_outputs > 1 the array is returned as-is.
Robustness omissions:
- The single-output branch flattens every element instead of removing just the output axis. If the input has shape (n_samples, k) with k != 1 (for example a caller passes the wrong n_outputs, or passes per-class probabilities), it quietly returns a vector of length n_samples*k with rows and columns mixed together, instead of rejecting the shape mismatch.
- Nothing checks that n_outputs is a positive integer (0 or negative values are accepted and silently treated as "multi-output").
- Nothing checks that, for n_outputs > 1, the array is actually 2-D with n_outputs columns.
- A 0-d (scalar) input with n_outputs == 1 is silently turned into a length-1 vector.
