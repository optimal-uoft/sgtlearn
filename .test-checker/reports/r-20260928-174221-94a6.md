## Suspicions

### sgtlearn-export-py--draw-internal-panel-pair

Logical mistakes: No definite flaw found on the happy path. The heatmap colours each (x-cell, y-cell) by routing a synthetic representative row through the node. Each sample is counted in at most one cell: the first x-cell it matches, then the first y-cell it matches inside that. Two subtle points are worth flagging. (a) The continuous cell-membership test is inclusive at both ends. A sample lying exactly on a shared cell boundary is therefore always counted in the lower cell, which may disagree with the side the node's thresholds actually route it to. The marginal count for that cell and the heatmap colour it sits under can then differ from the true routing. (b) A sample that matches an x-cell but no y-cell is dropped from the counts without any notice. Examples are a continuous value outside the plotted cell extent, or a categorical row whose active column is not one of the axis columns but is also not classed as missing. Samples like this vanish from both marginals.
Robustness omissions: The node is not checked for being a pair node, and there is no check that "pair_axes" holds exactly two axes with a valid "kind" of "continuous" or "categorical". The code does not check that X_rows is 2-D or has enough columns for the referenced column indices. If the palette is shorter than the number of partitions, the result is an IndexError instead of a clear error. The fontsize check treats a bool as an int. The continuous histogram range assumes at least one finite cell. If the non-missing cells are missing or degenerate, histogram setup may fail or look wrong. Finite values outside the cell extent are silently left out of the histogram.
