## Suspicions

### sgtlearn-export-py--draw-leaf-text

Logical mistakes: No clear happy-path error. Classifier leaves show the class with the highest count in the first output. On a tie the first (lowest) index wins, which is the usual argmax convention. Regressor leaves show the value formatted to `precision` decimals. The primary line is always drawn. The subtitle (sample count, plus impurity when requested) is drawn only for label='all'. With label='none' or any other label (for example 'feature' or 'root') only the bold line is drawn. This matches the docstring. One small quirk: the subtitle font size is "fontsize - 1" only when fontsize is an int. A float fontsize falls back to the default size, and fontsize=1 gives a size of 0.
Robustness omissions:
- class_names shorter than the number of classes causes an IndexError instead of a clear error or a fallback to the index string.
- Missing keys ('value' for regressors, 'n_samples' and 'impurity' for label='all') raise a raw KeyError.
- A flat (non-nested) class_counts, or a non-scalar regression value (array or multi-output), is not handled. It either raises or gives wrong output.
- An empty or missing class_counts silently gives an empty bold label. This is tolerated rather than reported.
- The label value is not validated. Unknown labels are treated like 'none'.
