### sgtlearn-base-py--sgtclassifier-tree-export

Robustness omissions: No definite omissions. Worth noting:
(1) The fitted check reads "_est" and "_le" by attribute. If a fit fails partway, "_est" can exist but be None, and the explicit None guard covers that case, so it stays. It should raise the same NotFittedError, with the standard message, as the sklearn check.
